## 本包离线验证

原有 57 个故障注入及输入检查测试随包迁移，另有便携路径和发行工具检查。测试不启动、关闭或连接 ANSYS，覆盖：

- 未收到用户输入时停止；草稿空值；导入阶段只读取几何。
- CAD/参数/实际几何变化后拒绝旧确认；位置属于当前几何、单位冲突拒绝。
- 重试次数上限、明确失败分类、仅使用已记录网格/子步备用参数。
- pending 不重复提交、不结束仍可能运行的会话；响应 ID 与请求重放防护。
- 不删除用户对象、保存顺序、数据库时间戳、结果有限值及安全系数复算。

仓库验证器额外检查元数据、链接、插件文件哈希、空白模板和常见敏感内容。发行工具采用文件范围限制生成 ZIP 并附校验和。自动检查只能覆盖列明的格式和模式，不保证发现所有隐私信息；发布者仍应审阅实际包内容。

最终离线运行结果见发行仓库的 `docs/VALIDATION_REPORT.md`。GitHub Actions 提供 Windows/Linux、Python 3.10/3.12 的后续检查配置；未在 GitHub 运行前不能宣称云端 CI 通过。

## 尚未完成的实机验证

此重新封装版本未启动 ANSYS，没有新增真实求解验收；旧案例不替代新包的运行验证。正式将版本描述为“新机已验证”前，至少完成一次干净安装、真实导入/询问/求解/保存/GUI 全流程，以及一个已有会话保留测试。

子步恢复、非扭转适配、其他 ANSYS 版本需要各自实机证据。网格收敛、反力平衡、解析对照按模型需求验证，不能由离线测试或 `Done` 状态推断。具体可复用检查表见仓库 `docs/RELEASE_CHECKLIST.md`。
