# CAD 导入静力分析：必读流程

在启动、关闭或脚本控制 Workbench/Mechanical 前完整阅读本文件。本流程保留原项目操作指南的前置检查和交付要求；本机路径、旧工况参数不作为默认值。

## 前置检查

1. 读取项目 `AGENTS.md` 和已有自动化指南，确定用户要求的工程、物理工况与最终 GUI 状态。
2. 核对 ANSYS 版本、RunWB2 实际路径、许可证及 ACT 文件队列插件。19.2 使用自带 IronPython；不能套用新版 PyMechanical 接口。
3. 列出现有 Workbench、Mechanical 和求解器进程，检查目标 `<name>_files/.lock` 与 `<name>.automation.lock`。优先复用用户会话，不得全局结束进程、抢锁或关闭用户窗口。
4. 核对 CAD 路径、文件大小、修改时间和 SHA-256；新建独立工程，不覆盖用户原件。确需覆盖时先确认已获相应授权，运行器还要求配置及 CLI 双重开关。
5. 明确本次隐藏会话的用途、归属、保存和退出条件。隐藏辅助进程不弹控制台；最终需要 GUI 时重新可见打开已保存工程。
6. 用 UTF-8 显式读取文本。对 19.2 journal，核对传给 `RunWB2 -R` 的路径和内容中的路径均可被正确解释。中文路径使用已验证的 Windows 8.3 短路径；不可用时选择用户可写的 ASCII 工作目录，不改系统 8.3 策略。
7. 为运行隔离队列、进度、请求、完成/中止标记和日志；新流程不能复用全局完成标记。用户已有会话不得接收本次受控队列。

## 导入和理解当前几何

创建 Static Structural 系统，把现有 CAD 设置到 Geometry，Refresh Model 后保存新 `.wbpj`。打开 Mechanical，只读取几何，不主动施加材料/边界/网格。

从 `ExtAPI.DataModel.GeoData.Assemblies` 枚举 Part/Body/Vertex/Face，记录：

- 实体数量、名称、实体类型；原生坐标单位及单位是否已经核验。
- X/Y/Z 范围、尺寸、主要特征和候选方向。几何长轴只是证据，不等于用户的加载轴。
- 相关面的当前 ID、面积、质心和法向/拓扑信息（可用时）；边、孔、接触面按实际工况识别。

对照已知尺寸核验单位，不能因界面显示 mm 就假定底层几何坐标也是 mm。“左端”“上孔”“整体向下”必须映射到当前几何；不足以唯一识别时给用户说明候选位置并提问。面 ID 随导入和拓扑变化而失效。

## 导入后收集工况

核对当前案例中已收到的信息，只询问缺失或含糊项：

| 信息 | 必须明确的内容 |
| --- | --- |
| 材料 | 牌号、热处理/供货状态、认可的参数来源、适用温度；E、ν、ρ、强度等与本次结果相关的参数 |
| 支承 | 具体位置、固定/位移/铰接/滑动等类型、允许的平移和转动自由度 |
| 载荷 | 位置、力/压力/力矩等类型、大小、单位、全局或局部坐标系、方向/正负号、分布及随时间变化情况 |
| 分析条件 | 静力类型、大变形、接触/摩擦、重力及其他工况、期望结果、精度/网格要求 |
| 杆件加载端 | 是否有导向；若有，限制哪些位移和转动，轴向转动是否自由 |

资料不足时保留导入工程并等待回答，不能使用“常见钢材”“一般载荷”等自行补齐。用户指定材料但未给参数时，可按其认可的数据来源查询；未经认可不能用历史材料强度。不能事后在报告写“假设”代替事前收集。

把真实回答、位置到几何的映射和参数来源记录下来。参数指纹只检测变更，不证明对话真实性；不得自动生成确认。完整回答不必再加一轮批准。

## 实施与监控

1. 按本次分析选择脚本；轴向扭转运行器只接受它能表达的工况。其他载荷须适配；不能替换工况以迁就代码。
2. 自定义材料先在独立 Engineering Data Library 验证 XML，再导入活动工程。读回材料名、关键性能及单位；同名不等于参数相同，运行器用参数指纹后缀区分材料。
3. 创建可追溯的几何选择和约束/载荷。核对实际面、力矩轴、单位及自由度。重跑只处理本次自动化拥有的对象；不能清空分析树。
4. 根据当前几何特征和精度要求确定网格，检查网格错误、节点和单元数。小特征/应力集中不能只凭单元数判断质量。
5. 添加等效应力、总变形及适用的安全系数结果。按本次设置求解。记录 request_id 和 response，短超时继续等待同一请求。
6. 只有可信终态响应可进入恢复。未决状态保留会话/请求/锁；不得启动另一个求解。数值备用参数必须针对当前模型记录，不改变材料、载荷、约束或大变形条件。
7. 核验 `analysis.State == UpToDate`、`solution.Status == Done`，检查结果数值和单位以及最新求解消息。

## 安全系数和物理合理性

19.2 原生 Stress Tool 在已观察案例中把安全系数封顶到 15，且存在单位显示异常。保留原生结果，同时用当前屈服强度和等效应力计算未截断结果；确认 `GetQuantityName() == Dimensionless` 并独立复算 `σy/σeq,max`。

只在均匀、延性材料且屈服判据适用时使用这一公式。脆性、复材、多材料、塑性历史或疲劳需要对应判据，不能推广此公式。`σeq=0` 时不可报告有限的比值。求解成功或重试成功不等于网格收敛；按精度要求核查反力平衡、变形趋势、解析对照和网格敏感性，对奇异应力说明解释范围。

## 保存与 GUI

先写独立结果文件，控制器核验后才写运行专属完成标记。对于自己创建的持有 journal，正确顺序为关闭本次 Mechanical 容器 `model_container.Exit()`，随后 `Save(Overwrite=True)`。不能把此操作用于用户已有、未获关闭授权的会话。

验证 `.wbpj` 及对应 `SYS.mechdb` 非空，修改时间不早于本次成功尝试，结果属于当前 run/attempt。用户要求可见打开时用 `RunWB2 -F <saved_project>`，确认目标窗口/进程、工程锁和新 session journal。运行器的锁/新 journal 检查属于自动证据；最终应观察实际窗口和加载工程，不能仅凭进程名宣称 Mechanical 结果视图已打开。

## 完整交付检查

- [ ] CAD 来源、实体数、尺寸、坐标单位和当前几何记录一致。
- [ ] 导入后已收集当前材料/热处理/来源、支承/自由度、载荷/位置/单位/方向和分析条件。
- [ ] 材料关键值读回正确；面、轴、自由度均来自当前几何和用户回答。
- [ ] 实际网格、节点/单元数、质量问题及重试使用的数值设置已记录。
- [ ] 状态 `UpToDate` / `Done`，最新日志无未处理求解错误。
- [ ] 最大等效应力、总变形及单位正确；原生/未截断安全系数和独立计算一致。
- [ ] 已完成用户所需的物理合理性/精度检查；未做的项目如实标注。
- [ ] `.wbpj` 和 `SYS.mechdb` 非空且时间戳有效，结果文本在案例目录中。
- [ ] 用户要求的 GUI 状态已实际确认，已有用户会话得到保留。
- [ ] 交付包含路径、物理输入、数据来源、结果、实际数值设置和限制。

任何一项缺失，说明当前停在哪个阶段，不以“仿真完成”概括尚未保存/验证的状态。
